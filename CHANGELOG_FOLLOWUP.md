## Existing Files Audit & Modifications

- **`checker.py`** — **Modified (Minimal Bug Fix)**
  - *What changed:* Added `ans = re.sub(r"\\text\{([^{}]*)\}", r"\1", ans)` to `clean_answer()`.
  - *Why:* Fixed a false-negative answer verification bug where string answers wrapped in LaTeX `\text{...}` (e.g. `\text{Evelyn}`) were not matching unwrapped plain strings (e.g. `Evelyn`). Numeric, fraction, and symbolic math comparisons remain unaffected.

## Newly Created Files

### 1. `stop_at_search.py`
- **Type:** New Script
- **Purpose:** Implements Task 1 experiment. Evaluates MATH-500 problems by passing `stop=["</search>"]` to Groq API. When search is triggered, generation stops at `</search>`, and a second turn resumes reasoning with an empty retrieval signal. Includes `max_tokens=1536` token capping and `detect_repetition_loop` detection to prevent infinite repetition loops from consuming rate limits.
- **Output Files Generated on Run:** `results/stop_at_search_results.csv`, `results/raw_stop_at_search.jsonl`

### 2. `search_rate_by_level.py`
- **Type:** New Script
- **Purpose:** Implements Task 2 analysis. Reads `results/pilot_100_results.csv` ($n=100$) and calculates search trigger rates, initial accuracy, 5-vote final accuracy, and net boost for each MATH-500 difficulty level (1–5) and overall.

### 3. `results/search_rate_by_level.csv`
- **Type:** New Data Output
- **Purpose:** Stores the tabular difficulty level breakdown generated by `search_rate_by_level.py` in CSV format.

### 4. `LEVEL_BREAKDOWN.md`
- **Type:** New Documentation Artifact
- **Purpose:** Presents the search trigger rate and performance metrics formatted as a markdown table with key observations.

### 5. `FOLLOWUP_PROGRESS.md`
- **Type:** New Documentation Artifact
- **Purpose:** Tracks experiment progress, status of tasks, remaining actions, and documents sample size reconciliation.

### 6. `no_tool_baseline.py`
- **Type:** New Script
- **Purpose:** Implements the No-Tool Baseline experiment. Runs MATH-500 problems using a plain Chain-of-Thought system prompt that makes zero mention of the `<search>` tool. Generates `results/no_tool_baseline_results.csv`, `results/raw_no_tool_baseline.jsonl`, and `NO_TOOL_COMPARISON.md`.

### 7. `NO_TOOL_PROGRESS.md`
- **Type:** New Documentation Artifact
- **Purpose:** Tracks execution progress, rate-limit events, and completed problem count for the No-Tool Baseline experiment.

### 8. `significance_test.py`
- **Type:** New Script
- **Purpose:** Performs McNemar's test for paired binary outcomes and computes 95% bootstrap confidence intervals comparing Tool-Offered vs. No-Tool Baseline conditions overall ($n=100$) and across difficulty levels (1–5).

### 9. `SIGNIFICANCE_RESULTS.md`
- **Type:** New Documentation Artifact
- **Purpose:** Tabulates statistical test results, $\chi^2$ statistics, exact p-values, 95% bootstrap CIs, and per-level sample size notes.

### 10. `charts/no_tool_vs_tool_accuracy.png`
- **Type:** New Visual Artifact
- **Purpose:** PNG chart visualizing cross-experiment accuracy across all 4 conditions (Tool Offered Initial, Stop-at-Search, No-Tool Baseline, 5-Vote Escalation).

### 11. `CHANGELOG_FOLLOWUP.md`
- **Type:** New Documentation Artifact
- **Purpose:** Session changelog detailing all created files and tracking minimal fixes to existing codebase files.
